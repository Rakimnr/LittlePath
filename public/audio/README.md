# LittlePath Audio Files

Place MP3 audio files here for the learning activities.

## Expected files

### Nursery (Sound Garden)
- `apple.mp3`
- `ball.mp3`
- `cat.mp3`
- `dog.mp3`
- `elephant.mp3`
- `fish.mp3`

### Grade 1-2 (Sound Garden)
- `cat.mp3` (shared)
- `sun.mp3`
- `fish.mp3` (shared)
- `tree.mp3`
- `book.mp3`
- `moon.mp3`

## Notes
- The AudioButton component gracefully handles missing files.
- Files should be standard MP3 format, short pronunciation clips (1-3 seconds).
- Clear, friendly pronunciation by a native speaker.
