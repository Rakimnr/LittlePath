# 🦋 LittlePath

**Small steps. Big discoveries.**

LittlePath is a colorful and interactive learning website designed for **nursery, Grade 1, and Grade 2 students**.  
It provides simple learning activities through a friendly butterfly mascot named **Pip** 🌈

The project is built as a **static React application** and deployed with **Vercel**.

---

## ✨ Features

- 🔊 **Sound Garden** — Learn letters and simple words with pronunciation
- ✏️ **Trace Trail** — Practice tracing letters and following simple paths
- 🧩 **Match Meadow** — Match pictures, letters, and words
- 🦋 **Pip the Butterfly** — A friendly mascot that guides children through the learning journey
- 🗺️ **Learning Map** — Move through activities using a playful learning path
- ⭐ **Celebration Screen** — Friendly feedback after completing activities
- 💾 **Local Progress** — Activity progress is stored using browser `localStorage`
- 📱 **Responsive Design** — Works on desktop, tablet, and mobile devices
- 🎨 **Child-Friendly UI** — Large buttons, soft colors, rounded cards, and simple animations

---

## 🎯 Project Goal

The goal of LittlePath is to create a **small, easy-to-use educational experience** for young children.

The interface focuses on:

- Simple navigation
- Large visual elements
- Minimal reading
- Friendly feedback
- Interactive learning
- Comfortable colors and animations

No login, database, or complicated setup is required.

## 🚀 Run Locally

### 1️⃣ Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2️⃣ Open the project

```bash
cd LittlePath
```

### 3️⃣ Install dependencies

```bash
npm install
```

### 4️⃣ Start the development server

```bash
npm run dev
```

Then open the local URL shown in your terminal.

---

## 📦 Production Build

Create a production build using:

```bash
npm run build
```

The generated production files will be available inside the:

```text
dist/
```

folder.

## 🌐 Deployment

LittlePath is designed for easy deployment with **Vercel**.

### Vercel configuration

```text

Root Directory    : ./
Build Command     : npm run build
Output Directory  : dist
Install Command   : npm install
```
